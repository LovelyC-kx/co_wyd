## 1. 论文一：VCPEN 的算法

### 1.1 符号与维度
- 图像分辨率 H×W = 32×32，N = H·W = 1024。
- 逻辑图案数 M（256 或 512），采样率 β = M/N。
- 可学习参数：行向量 r_m ∈ R^{1×H}、列向量 c_m ∈ R^{1×W}，m = 1..M；共 M·(H+W) = M·64 个图案参数（对比逐像素可学习图案 M·1024）。
- U-Net 参数 θ。

### 1.2 算法 1.1：Rank-2 逻辑图案合成（式 (1)）

```
输入: 连续实值向量 r_m ∈ R^H, c_m ∈ R^W
1. r_b = Binarize(r_m)            # {0,1}^H，前向硬阈值，反向 STE
2. c_b = Binarize(c_m)            # {0,1}^W
3. A = outer(r_b, 1 - c_b)        # H×W, Rank-1
4. B = outer(1 - r_b, c_b)        # H×W, Rank-1
5. P_m = A + B                    # H×W, Rank ≤ 2, 元素 ∈ {0,1}
输出: P_m
```

关键性质（由式 (1) 直接推出）：
- A 与 B 的支撑不相交：A 非零要求 r_b(x)=1，B 非零要求 r_b(x)=0，因此 P_m 仍是二值矩阵，不会出现 2。
- 逐元素展开：P_m(x,y) = r_b(x)(1−c_b(y)) + (1−r_b(x))c_b(y) = r_b(x) XOR c_b(y)。也就是说，Rank-2 图案等价于“行激活位与列激活位的异或”。这解释了为什么它比单个 Rank-1 外积（AND 逻辑）有更丰富的空间结构：AND 图案只能是“若干行 × 若干列”的矩形网格，XOR 图案在每一行是 c_b 或其补，形成棋盘式结构。
- 负相图案 P_m− = 1 − P_m = r_b(x) XNOR c_b(y) = outer(r_b, c_b) + outer(1−r_b, 1−c_b)，同样是两个 Rank-1 矩阵之和（A′、B′）。
- Fig. 2(b) 的例子：r_b=[1,0,0,1,1]，c_b=[0,1,0,1,1]：第 1、4、5 行为 1−c_b=[1,0,1,0,0]，第 2、3 行为 c_b=[0,1,0,1,1]。

二值化（补充材料 S3，正文只说明使用 straight-through estimator）：实现上通常为
```
前向: r_b = (r_m > 0).float()      或 (sigmoid(r_m) > 0.5)
反向: ∂L/∂r_m := ∂L/∂r_b          # 把阈值函数的梯度当作恒等（或 sigmoid 导数）
```
原文未给出阈值、是否使用 sigmoid 预激活、是否有温度参数，这些需自行选择。

### 1.3 算法 1.2：分解为四步硬件投影
```
输入: P_m (由 r_b, c_b 生成)
步骤 1: 投影 A  = outer(r_b, 1-c_b)     # 行使能=r_b, 列使能=1-c_b
步骤 2: 投影 B  = outer(1-r_b, c_b)     # 行使能=1-r_b, 列使能=c_b
步骤 3: 投影 A' = outer(r_b, c_b)       # 行使能=r_b, 列使能=c_b
步骤 4: 投影 B' = outer(1-r_b, 1-c_b)   # 行使能=1-r_b, 列使能=1-c_b
每一步: FPGA 把行使能向量、列使能向量写到 64 路 I/O，驻留 t0（实验 20 μs），
        DAQ 以 2 MS/s 采样探测器电压并积分为一个桶值 D_step
```
- 每一步都是纯 Rank-1（一个行向量 × 一个列向量），行列寻址电路可以直接实现。
- 时间预算：每个逻辑图案 4·t₀ = 80 μs；M=256 → 20.48 ms ≈ 48.8 fps（文中记 50 fps）；M=512 → 40.96 ms ≈ 24.4 fps（文中记 25 fps）。
- t₀ 的下限由调制器载流子寿命决定（12 μs 硅片取 20 μs，t₀ 必须大于 T_life，否则载流子密度未达稳态、调制深度不足）。

### 1.4 算法 1.3：差分桶信号
探测是线性的，因此对不相交支撑的 A、B 有 D(A)+D(B) = D(A+B) = D(P_m+)。定义差分桶信号（原文式 (2) 给出的是理想桶信号 D_m = Σ P_m O，差分实现方式由 Sec. II.B.1 的文字描述推得）：
```
D_m+ = D_A + D_B           # 正相桶值
D_m- = D_A' + D_B'         # 负相桶值
D_m  = D_m+ - D_m-         # 差分桶值
```
性质：D_m = Σ_{x,y}(2P_m − 1)O = 2·Σ P_m O − Σ O。差分消去了与图案无关的直流分量（环境光、探测器偏置 −0.75 V 基底）与两次投影间共模的源功率波动。注意 A、B、A′、B′ 四次投影在时间上顺序进行，只有慢于 80 μs 的漂移能被抑制。

### 1.5 算法 1.4：DGI 重建（式 (3)）
```
输入: 图案 {P_m} (M×H×W), 桶信号 {D_m} (M)
1. S_m = P_m.sum()                         # 每个图案的透光像素数
2. mean_P = P.mean(axis=0)                 # H×W
3. mean_S = S.mean()
4. mean_PD = (P * D[:,None,None]).mean(axis=0)   # H×W
5. mean_SD = (S * D).mean()
6. O_DGI = mean_PD - (mean_P / mean_S) * mean_SD
输出: O_DGI (H×W)
```
- 推导要点：普通鬼成像 O_GI = ⟨PD⟩ − ⟨P⟩⟨D⟩ 用 ⟨D⟩ 估计背景；DGI 用 S_m 归一化后的 ⟨SD⟩/⟨S⟩ 替代 ⟨D⟩，等价于把每个桶值按照该图案的总光通量重新加权，消除图案间总光强不同带来的偏置，从而抑制共模噪声。
- 复杂度：O(M·N)，M=512、N=1024 时约 5×10⁵ 次乘加，可忽略不计；非迭代、无超参数。
- 训练时 DGI 完全可微（只有乘法和平均），梯度可从 O_DGI 反传到 P_m 再经 STE 到 r_m、c_m。

### 1.6 算法 1.5：端到端训练（式 (4)(5)）
```
超参数: lr=1e-3, batch=512, 优化器未说明（Adam 为通常选择）, 损失 L2
数据: MNIST 60000 训练 / 10000 测试, resize 32×32, 归一化灰度
可学习: {r_m, c_m}_{m=1..M}, θ (4 级 U-Net)

for epoch:
  for batch O (B×1×32×32):
    P = stack_m Rank2Synthesize(r_m, c_m)          # M×32×32, 二值(STE)
    D = einsum('mhw,bhw->bm', 2P-1, O)             # 仿真差分桶信号; 可选加噪
    O_dgi = DGI(P, D)                              # B×1×32×32
    O_dl  = UNet_θ(O_dgi)                          # B×1×32×32
    loss  = ||O_dl - O||_2^2 (对 batch 平均)
    loss.backward(); step()                        # 同时更新 θ 与 r, c
```
- 仿真噪声：噪声鲁棒性实验中噪声是加在真值图像上（SNR_dB = 10 lg(P_image/P_noise)），而非桶信号上；这与实测中噪声主要来自探测端不同，但作者用相同条件比较所有方法。
- 训练完成后 {r_b, c_b} 固定，导出为 FPGA 行列时序；U-Net 用于实测数据的推理。
- 推理流程：硬件按 4M 步采集 → 组合成 M 个差分桶值 → DGI → U-Net → 输出帧。DGI + U-Net 的推理时间远小于 20 ms 的采集时间，因此帧率由采集决定。

### 1.7 为什么 Rank-2 而不是 Rank-1 或更高
- Rank-1（单次外积）：可用图案集合太小（矩形网格），测量矩阵行之间高度相关，重建病态。
- Rank-2 XOR：仍只需 H+W 个参数，一个逻辑图案的等效测量矩阵行 vec(P_m) 可以覆盖类似 Walsh–Hadamard 的“可分离 ±1”结构（若 r_b、c_b 取 Walsh 序列，2P−1 = (2r−1)ᵀ(2c−1)·(−1)，恰为可分离 Hadamard 图案）。这就是为什么对比方法可以用相同硬件投影 Walsh–Hadamard 图案。
- 更高秩：需要更多投影步（秩 k 至少 2k 步含差分），线性降低帧率。Rank-2 是“编码复杂度 vs. 时间成本”的折中。

### 1.8 载流子寿命约束的定量表述
- 调制深度 m(t₀) 随 t₀ 增长并饱和（Fig. 7(d)）；t₀ < T_life 时载流子处于瞬态积累阶段，m 显著下降，重建 SNR 与结构都劣化。实验扫描 t₀ ∈ [5, 320] μs，三种硅片 T_life = 12/26/100 μs。
- 帧率上限 fps_max ≈ 1/(4·M·t₀)，t₀ ≳ T_life。要在 M=256 下超过 50 fps 需要 T_life < 20 μs 且调制深度足够（材料方向：GaAs、离子注入硅）。

## 2. 论文二：DL-MFIF 的算法

### 2.1 算法 2.1：DIV2K 退化仿真（式 (10)）
```
for each DIV2K image:
  g  = to_gray(img)
  HR = bilinear_resize(g, 120×120)
  LR0 = bilinear_resize(g, 30×30)
  k  = random_choice({3,5,7,9,11})
  σx, σy ~ U[1, 9]
  K  = anisotropic_gaussian(k, σx, σy)       # 式(10): (2πσxσy)^{-1/2} exp(-(x²/σx²+y²/σy²)/2)，再归一化
  LR = conv2d(LR0, K, padding='same')
  save (LR, HR)
共 800 对，8:2 划分
```
注意：模糊是施加在已经下采样到 30×30 的图像上（而不是先模糊再下采样），核尺寸最大 11×11 相对 30×30 的图像已是很强的模糊，用来模拟 THz 大 PSF。

### 2.2 算法 2.2：ESRT 单分支前向（据 Fig. 3 与 Sec. 3.1.1）
```
x: [B,1,30,30]
f0 = Conv3(x)                                   # 浅层低频轮廓
f1 = LCB(f0) = HPB ∘ ... ∘ HPB (f0)             # 高保持块: 自适应平均池化压缩 + 可微滤波保留高频; 残差路径带可学习缩放
f2 = LTB(f1) = ET ∘ ... ∘ ET (f1)               # 高效 Transformer: 局部窗口多头注意力 + FFN
f3 = Conv3(f2); f3 = PixelShuffle_x4(f3); f3 = Conv3(f3)
s  = Conv3(PixelShuffle_x4(x))                  # 跳跃分支 (需要先把通道扩到 16 倍; 具体由实现决定)
y  = f3 + s                                     # [B,1,120,120]
```
损失：MSE(y, HR)。HPB/ET 的层数、通道数、窗口大小原文未给，遵循 ESRT 原论文（Lu et al. 2022）默认设置。

### 2.3 算法 2.3：SR-DESRT + CA-ResBlockCBAM 的 Stage I 训练
```
预训练: ESRT_DIV2K ← 在 800 对 DIV2K 上训练 (MSE, Adam, lr 1e-4→1e-6 余弦退火, 200 epoch, batch 16)
初始化: ESRT_THz ← 拷贝 ESRT_DIV2K 权重 (原文说"fine-tuned", 隐含从预训练权重出发)
冻结:   ESRT_DIV2K.requires_grad = False

for epoch in 1..200:
  for batch (LR_k, HR_k) in THz 数据 (batch 16, 各频点图像独立成样本):
    y1 = ESRT_THz(LR_k)              # [B,1,120,120]
    y2 = ESRT_DIV2K(LR_k)            # [B,1,120,120], no_grad
    F  = concat([y1, y2], dim=1)     # [B,2,120,120]
    out = CA_ResBlockCBAM(F)         # [B,1,120,120]
    loss = MSE(out, HR_k)
    更新 ESRT_THz 与 CA_ResBlockCBAM
```
CA-ResBlockCBAM 结构（Fig. 4(a)，通道数按图中标注）：
```
F [2,120,120]
→ ResBlockCBAM → Conv2d(→18)
→ ResBlockCBAM → Conv2d(→18)
→ ResBlockCBAM → Conv2d(→18)
→ ResBlockCBAM → Conv2d(→18)
→ Conv2d(→12) → Conv2d(→6) → Conv2d(→3) → Conv2d(→1)
```
ResBlockCBAM（Fig. 4(b)，式 (1)(2)）：
```
def ResBlockCBAM(X):                      # X: [B,C,H,W]
  F  = Conv(X)
  Mc = sigmoid(MLP(AvgPool_hw(F)) + MLP(MaxPool_hw(F)))    # [B,C,1,1]; MLP 共享权重, 隐层带缩减比
  F1 = F * Mc
  Ms = sigmoid(Conv_k([AvgPool_c(F1); MaxPool_c(F1)]))     # [B,1,H,W]; 通道维池化后拼接 (2通道) 再卷积
  F2 = F1 * Ms
  return X + F2                            # 残差
```
原文没有给出 MLP 的缩减比、空间注意力卷积核尺寸（CBAM 原文为 7×7）以及首个 ResBlockCBAM 如何把 2 通道映射到 18 通道（图中残差块输出即 18 通道，故第一个卷积应做通道提升，残差支路需要 1×1 卷积匹配或省略残差）。

### 2.4 算法 2.4：MFIF-GA 精英遗传算法多频融合

#### 2.4.1 个体编码
对一个样品有 n 幅第一阶段输出 I_0..I_{n−1}（n=13：12 个频点 + 1 个时域最大值图；评价时未说明是否包含时域图，Fig. 5 以 f1..f12 示意）。个体 x = (W, S, G)：
- W ∈ Δ^{n−1}（单纯形）：融合权重，W_k ∈ [0,1]，Σ W_k = 1；初始化 W ~ Dir(α)（式 (3)），α 取值原文未给（对称 α=1 为均匀单纯形采样）。
- S ∈ R^n：各频点高斯去噪核 σ_k，均匀分布初始化，范围未给。
- G ∈ R^n：各频点对比度系数 γ_k，均匀分布初始化，范围未给。
基因长度 3n。

#### 2.4.2 解码（融合，式 (4)(5)(6)）
```
def decode(x, {I_k}):
  for k: 
    I1_k = gaussian_blur(I_k, σ=S_k)                 # 式(4) 核: (2πσ²)^{-1} exp(-(i²+j²)/2σ²)
    I2_k = clip(G_k * (I1_k - 0.5) + 0.5, 0, 1)      # 式(5): 绕 0.5 拉伸对比度; 像素已归一化到 [0,1]; clip 为实现需要
  I_out = Σ_k W_k * I2_k                             # 式(6)
  return I_out
```

#### 2.4.3 适应度（式 (7)(8)(9)）
```
def SMD(I):      return Σ_ij (|I[i,j]-I[i,j-1]| + |I[i,j]-I[i+1,j]|)       # 灰度差分和(越大越清晰)
def NRI_SNR(I):  return mean(I) / sqrt(var(I))                             # 无参考信噪比(越大越干净)
def fitness(x):  I = decode(x); return 0.5*SMD(I) + 0.5*NRI_SNR(I)
```
实现注意：SMD 是对 120×120 像素求和，量级为 10²–10³；NRI-SNR 量级为 1–10。原文按 α=β=0.5 直接线性相加，未提归一化。若严格照做，SMD 会主导适应度，GA 会偏向高梯度解；作者的结论“GA 兼顾清晰度与噪声”说明其实现可能对两项做了尺度处理（或 SMD 取均值）。复现时建议把两项分别做 min-max 或 z-score 归一化后再加权，并把这一选择写进实验记录。

#### 2.4.4 精英 GA 主循环（Fig. 5(a)）
```
超参数: 初始种群 P0=6000, 代数 T=20, 变异概率 pm=0.25, 精英率 e=0.10, 种群上限 7000
pop = init(P0)                              # W~Dirichlet, S,G~Uniform
for t in 1..T:
  fit = [fitness(x) for x in pop]           # 每个个体一次解码 + 两项指标
  elites = top_k(pop, fit, k=e*len(pop))    # 直接保留
  parents = selection(pop, fit)             # 选择算子未指明(轮盘赌/锦标赛)
  children = crossover(parents)             # 交叉算子未指明; 对 W 交叉后需重新归一化到单纯形
  children = mutate(children, pm)           # 变异算子未指明; 对 W 变异后重新归一化, S,G 保持在范围内
  pop = elites ∪ children                   # "combine old and new population"
  if len(pop) > 7000: pop = top_k(pop, 7000)
best = argmax fitness(pop)
I_final = decode(best)
```
复杂度：每代约 6000–7000 次解码，每次解码 n 次高斯滤波 + 一次加权求和 + 两个指标（均为 O(n·H·W)，H=W=120）；20 代约 1.3×10⁵ 次解码，对应 Table 2 的 6.5 min（CPU）。加速手段：先对每个 (k, σ) 组合缓存滤波结果（σ 离散化），或用向量化批量评估。

#### 2.4.5 评价用图像的选取规则
- DL-MFIF：直接评价 I_final。
- 无 GA 模块的方法：取 best.W 中权重最大的频点 k* 对应的图像作为该方法的代表（样品 6、7 均为 0.1 THz）。这保证不同方法在同一频点上比较。

### 2.5 两种对照融合算法
```
GF (梯度融合):
  g_k = |Sobel(I_k)|;  I_out[i,j] = I_{argmax_k g_k[i,j]}[i,j]         # 逐像素选梯度最大的频点
MWA (指标加权平均):
  s_k = entropy(I_k);  w_k = s_k / Σ s;  I_out = Σ w_k I_k
```

### 2.6 无参考指标的精确定义（Sec. 4.3）
- 方差：全图像素方差。
- 对比度：8×8 非重叠窗口（stride 8）内 (max − min) 的均值，120×120 图像有 225 个窗口。
- 信息熵：−Σ p(g) log₂ p(g)，灰度直方图。
- 平均梯度：Sobel 水平/垂直梯度幅值的均值。

## 3. 论文三：PCA-based THz-SSDD 的算法

### 3.1 算法 3.1：频率相关 PSF 的解析生成（式 (8)–(10)）
```
输入: 频率区间 [f_i, f_e], 像素尺寸 Δ (扫描步长 0.5 mm), 核半径 K
f  = (f_i + f_e)/2
λ  = c / f
ω0 = 2λf_lens/(π D)          # 透镜 f/D = 4 时 ω0 ≈ 2.547 λ
σ  = ω0/√2 ≈ 1.8 λ           # 换算到像素: σ_px = σ/Δ
h  = exp(-(x²+y²)/(2σ²)) 在 (2K+1)×(2K+1) 网格采样, 归一化到和为 1     # 式(9)
```
式 (10) 的 3D 形式 h(x,y,f) = f²/(6.48πc²)·exp(−f²(x²+y²)/(6.48c²)) 就是把 σ=1.8λ=1.8c/f 代入式 (9)（1.8²·2 = 6.48）。2D 网络只用中心频率的一个核。作者强调训练中网络会“自动优化以匹配输入 PSF”，即 PSF 只需近似。

### 3.2 算法 3.2：Recorrupted-to-Recorrupted 配对（式 (5)）
```
输入: 噪声图像 y (单幅主成分图像或谱图像), 5×5 均值滤波 H, 背景电平 b, 矩阵 D (可逆; 原文取单位阵类)
Σ_y = diag(max(H(y) - b, ε))          # 局部方差估计: 平滑后的信号减背景, 对应泊松噪声 var ∝ 信号
n   = sqrt(Σ_y) ⊙ randn_like(y)        # n ~ N(0, Σ_y), 逐像素独立
ŷ   = y + Dᵀ n                          # 网络输入
ỹ   = y − D⁻¹ n                         # 监督目标
```
理论依据（R2R，Pang et al. 2021 的核心论断，此处给出简化推导）：设 y = x + e，e ~ N(0, Σ)，n ~ N(0, Σ) 与 e 独立，D = I 时
- ŷ − x = e + n，ỹ − x = e − n；Cov(e+n, e−n) = Σ − Σ = 0，高斯情形下两者独立。
- 于是 E‖f(ŷ) − ỹ‖² = E‖f(ŷ) − x‖² + E‖e − n‖²，第二项与 f 无关，最小化自监督损失等价于最小化对干净图像的监督损失。
- 一般可逆 D 需满足 Dᵀ Σ_z D⁻ᵀ = Σ 的交换关系（例如 D = αI）；这也是原文“invertible identity matrix”的含义。
- 用 diag(H(y) − b) 作为方差是把信号相关（泊松型）噪声近似为方差正比于局部均值的高斯噪声；Table II 的“training noise level 25”是另一个全局噪声尺度参数（对 8-bit 归一化图像通常指 σ=25/255），原文未说明它与 Σ_y 的组合方式。

### 3.3 算法 3.3：THz-SSDD 训练（式 (7)，Fig. 1）
网络：两个 U-Net（Fig. 1 画的是 UNet++ 式密集跳连结构，节点 X^{i,j}，5 级下采样，双输出 L₁、L₂）。记去噪输出 z₁ = f_θ^den(ŷ)，去模糊输出 z₂ = f_θ^deconv(z₁ 或 ŷ)；原文式 (7) 统一写作 f_θ(ŷ)。
```
超参数: batch 16, epoch 100, lr 1e-3, Adam, Kaiming 初始化, 噪声水平 25, 权重 ξ, γ (未给数值)
for epoch:
  for batch y (来自 GFRP 的 200 幅谱图像/主成分图像):
    ŷ, ỹ = R2R_pair(y)
    z = f_θ(ŷ)
    L_den   = ||z − ỹ||²                                # 第一项: 像素级自监督去噪
    L_blur  = ||downsample(conv2d(z, h_f)) − ỹ||²       # 第二项: 重模糊一致性, 驱动反卷积
    L_hess  = ||∇² z||_1                                # 第三项: Hessian 范数 (二阶差分 z_xx, z_xy, z_yy 的 L1), 抑制伪高频
    loss = L_den + ξ L_blur + γ L_hess
    step()
```
- 第二项是“重模糊一致性”：若 z 是去模糊后的图像，z ⊗ h_f 应回到（去噪后的）观测。单独用第二项（式 (6)）会把噪声也当成需要“反模糊”的信号而放大，因此必须与第一项联合。
- 下采样算子 (·)↓ 匹配测量网格；点扫描步长与图像网格一致时可为恒等。
- Fig. 4(a) 的曲线在 50 epoch 内收敛；训练约 4 h。
- 推理时 GFRP 训练得到的 θ 直接用于其他材料与测量模式（作者称零样本自监督）。

### 3.4 算法 3.4：谱维 PCA 分解与重建（式 (11)–(15)）
```
输入: 谱图像立方体 X ∈ R^{H×W×B} (B 为频点数, 例如 0.03–2 THz 以 1.2 GHz 分辨率), r (取 5)
1. Y = reshape(X, [B, N]),  N = H·W                   # 每列是一个像素的谱向量
2. μ = Y.mean(axis=1, keepdims=True); Ỹ = Y − μ       # 沿像素方向去均值 (每个频带减去该频带均值)
3. C = Ỹ Ỹᵀ / (N − 1)                                 # B×B 协方差 (式(12) 写作 X̃ᵀX̃/(n−1), 维度含义相同)
4. (λ, V) = eigh(C); 按 λ 降序排序
5. E = V[:, :r]                                       # B×r
6. Z = Eᵀ Ỹ                                           # r×N, 第 i 行 reshape 为 H×W 即第 i 幅主成分图像
7. for i in 1..r: Z_i ← f_θ(Z_i)                       # 用 THz-SSDD 先去噪再反卷积 (Fig. 5 分两步)
8. Ŷ = E Z + μ                                        # B×N (式(15) 省略了加回均值; 实现时必须加回)
9. X̂ = reshape(Ŷ, [H, W, B])
```
- 维度选择：保留解释 95%–99% 方差的 r；本文 r=5，观察到第 2 个 PC 之后信息量骤降。r 太小丢结构，r 太大则噪声成分被保留、去噪去模糊效果弱。
- 复杂度：协方差 O(B²N)，特征分解 O(B³)，投影/重建 O(BrN)；B 通常数百，N 数千到数万，都很轻。网络推理仅 r 次，而不是 B 次，这是 PCA 带来的第二个好处。
- 为什么有效：低频模糊与高频噪声在谱维上是相关的退化，被压缩到少数主成分（PC-1 主要是结构与错位噪声，PC-3..5 主要是高斯噪声）；对主成分图像做去噪/去模糊后线性重建，所有频点同时受益。
- 主成分图像的数值范围与原谱图像不同（可正可负），送入网络前需要做归一化（原文未提，实现时需注意），R2R 的方差估计 H(y)−b 对负值也需保护。

### 3.5 算法 3.5：完整流水线（Table I）
```
1. X_time (H×W×T) → FFT 沿时间轴 → 幅值谱 X (H×W×B)
2. 用 X (或其主成分) + PSF 训练 THz-SSDD (仅 GFRP)
3. 对任意测试立方体: PCA 分解 → 取前 r 个 PC
4. 每个 PC: 去噪 (THz-SSDD) → 反卷积 (THz-SSDD)
5. PCA 重建 → 全部频点的复原谱图像
```

### 3.6 指标算法
- PSNR（式 (16)）：PSNR = 10 log₁₀(255² / (1/(MN) Σ|T − I|²))，T 为输出、I 为输入。这是“处理前后差异”的对数度量，值越高表示改动越小；文中把它作为质量指标使用，读者需注意其含义与常规“对真值的 PSNR”不同。
- RSE（式 (17)）：RSE = ‖E_proc − E_orig‖_F / ‖E_orig‖_F，对每个样品在整个 (x,y,f) 立方体上计算；约 0.4 表示处理改变了约 40% 的谱能量范数。

## 4. 论文四：THz-Net 的算法

### 4.1 算法 4.1：退化数据合成（式 (1)(2)）
```
输入: DIV2K 干净图 x, 放大倍率 s ∈ {2,3,4}, 高斯核宽 ρ, 噪声 β
1. x_blur = conv2d(x, G_ρ)                    # G_ρ(u,v) = (2πρ²)^{-1} exp(-(u²+v²)/2ρ²)
2. y0     = downsample(x_blur, s)             # S(·): 采样/离散化
3. y      = y0 + β·randn                      # 加性高斯噪声
4. 随机裁剪训练 patch (HR 192×192, LR 192/s)
```
ρ、β 的取值与是否随机化原文未给；跨系统泛化的效果说明训练时很可能覆盖了一定范围的 ρ、β。

### 4.2 算法 4.2：THz-Net 前向传播
```
y: [B,1 或 3, h, w]
F0 = Conv3x3(y)                                     # 浅层特征, C 通道 (64)
X = F0
feats = []
for l in 1..N (N=32):
    T = Conv3x3(ReLU(Conv3x3(X)))                   # 残差分支: Conv–ReLU–Conv, 无 BN
    X = X + α·T                                     # α=0.05 (最终配置); 相加后无 ReLU
    if l in {N-2, N-1, N}: feats.append(X)          # "最后三个阶段"; 阶段划分粒度原文未明
FN = X + F0                                         # 全局残差
F1c, F2c, F3c = feats                               # 多尺度特征 (Part 2)
for i in 1..3:
    F = Fic
    Mch = sigmoid(W1(W0·AvgPool_hw(F)) + W1(W0·MaxPool_hw(F)))    # 式(7), 共享 MLP, 缩减比 r
    F  = F * Mch                                                   # 式(6) 第一步
    Msp = sigmoid(Conv7x7([AvgPool_c(F); MaxPool_c(F)]))           # 式(8)
    F̂ic = F * Msp                                                  # 式(6) 第二步, 式(9)
Fcat = concat(align_resolution(F̂1c, F̂2c, F̂3c), dim=1)              # Part 4: 对齐 (若尺寸相同则直接拼接)
Ffuse = Conv(Fcat)
x̂ = Upsample_s(Ffuse) = [Conv → PixelShuffle(2)] ×log2(s) 或 [Conv → PixelShuffle(3)]   # Fig. 2(a)(iii)
    → Conv → 输出通道
```
- Fig. 1 中 F₁^C、F₂^C、F₃^C 画在不同的空间尺度上（金字塔形），但正文的 F_i^C ∈ R^{C_i×H_i×W_i} 与“aligned to a common resolution”暗示可能存在下采样/上采样对齐；具体对齐方式（插值或反卷积）未说明。
- 去 BN 的理由：BN 会把每通道强度分布标准化，抹掉 THz 图像中位于低强度区的结构信号；去掉相加后的 ReLU 保持残差和的负值分量以保留局部对比度。

### 4.3 算法 4.3：训练与评估
```
超参数(最终): epoch 20, lr 5e-6, Adam, MSE, batch 32, patch 192, ResBlock 32, 残差缩放 0.05
数据: DIV2K 800 训练 / 100 验证测试; 全部经算法 4.1 退化
评估: 三系统 THz 图像 → 网络 → RGB→YCbCr → 在 Y 通道计算 PSNR/SSIM; 三系统平均
```
- 学习率 5e-6 非常小，与 20 epoch 组合意味着训练很短（Table 4 显示 50 epoch 反而略降），推测模型从某个预训练初始化出发或数据量足够大；原文未说明。
- 复杂度：32 个残差块 × 2 个 3×3 卷积 × 64 通道，对 192×192 patch 每个 3×3 卷积约 1.36 GFLOPs，骨干约 87 GFLOPs/patch，属于 EDSR 级别的中等模型。

### 4.4 消融算法变体

- w/o SAM：只保留通道注意力。

## 5. 论文五：非线性 THz-CT 的算法

### 5.1 几何与测量的离散化
- 域 Ω：半径 R 的圆盘。射线由平台旋转角 θ 与平移 s 索引，i = (θ, s)；PE 实验取 θ ∈ {0°,10°,…,180°}（19 个）、s ∈ {0,10,…,70} mm（8 个）→ I = 152 条射线。
- 每条射线初值：p₀ 在圆盘外沿探测方向的起点，w₀ 为单位方向向量（由 θ 决定），s 决定平行偏移。
- 参考路径长度 |L_r|：无样品时射线在探测器与源之间的直线长度（实际由参考脉冲 T₀ 给出，Δd = c₀(T − T₀)）。

### 5.2 算法 5.1：迭代射线传播（Algorithm 1 + 式 (10)–(14)）
```
输入: 当前段 L_v = {p_v + t w_v}, 界面集合 S̃, 折射率 n_v (当前介质), n_{v+1} (跨界面后的介质)
1. t_ξv, ξv = nearest_intersection(p_v, w_v, S̃)      # 沿 w_v 方向最近的界面交点参数与界面编号
2. p_{v+1} = p_v + t_ξv · w_v                           # 交点
3. n_p = interface_normal(S_ξv, p_{v+1})                # 界面在交点处的单位法向 (线段: 垂直于方向向量; 圆: 径向)
4. θ1 = arccos(|⟨w_v, n_p⟩| / (|w_v||n_p|))             # 式(10) 入射角 ∈ [0, π/2]
5. θ2 = arcsin(n_v sin θ1 / n_{v+1})                    # 式(11) Snell
6. Δθ = ±(θ1 − θ2)                                      # 式(12); 符号由 sign(cross(w_v, n_p)) 与法线朝向决定
7. w_{v+1} = R(Δθ) w_v,  R(Δθ) = [[cos Δθ, −sin Δθ],[sin Δθ, cos Δθ]]   # 式(13)(14)
8. 返回 L_{v+1} = {p_{v+1} + t w_{v+1}, t ∈ [0, t_ξ{v+1}]}
终止: 射线离开圆盘 Ω (再无交点) → 最后一段到探测器
```
实现细节（原文未展开，但复现必需）：
- 线段界面 S_ξ = {A + t(B−A)} 的射线求交：解 p_v + τ w_v = A + t(B−A)，τ>ε 且 t∈[0,1]；圆环界面求交解一元二次方程 |p_v + τ w_v − c|² = r²，取最小正根。
- 从哪个介质进入哪个介质（n_v → n_{v+1}）需要拓扑判断：对圆环模型可用“穿过内圆/外圆的次数”判断当前在环内、环壁还是环外；对多边形字母模型用点在多边形内测试（射线穿越计数）。
- 当 n_v sin θ1 / n_{v+1} > 1（全反射）时 arcsin 无定义；原文未讨论，实现时应视为该射线无效或以反射处理。
- 折射角符号：把 w_v 向法线方向“折向”还是“折离”取决于 n_v < n_{v+1} 还是 n_v > n_{v+1}，以及入射方向相对法线的左右侧；用 2D 叉积符号可统一处理。

### 5.3 算法 5.2：非线性正算子 H(N,S)（式 (15)(16)）
```
def H_i(N, S, p0_i, w0_i):
    segs = trace(p0_i, w0_i, S, N)           # 算法 5.1 循环, 返回 [(t_ξ0, n_0), (t_ξ1, n_1), ..., (t_ξV, n_V)]
    return Σ_v t_ξv · n_v − |L_r,i|          # n_0 = 1 (空气)
```
- 对第 i 条射线，H_i 对 N 是分段线性的（给定路径时），但路径本身随 N 和 S 变化（Snell 定律），因此整体非线性；对界面参数（如斜率 k_ξ）因交点参数 τ 的分母含 k_ξ 而非光滑。
- 一次评估的复杂度 O(V·|S̃|)（每段要与所有界面求交），整幅正弦图 O(I·V·|S̃|)。

### 5.4 算法 5.3：差分进化求解折射率与界面（Algorithm 2）
```
输入: g_ref (I 维), 参数上下界 B = {(N_min,N_max), (S_min,S_max)}, D = dim(N)+dim(S)
超参数: NP = 10·D, CR = 0.9, λ(缩放因子 F) = 0.8, K_max
1. 初始化 GP^0 = {x_m ~ U(B)}_{m=1..NP},  x = (N, S)
2. for k in 0..K_max−1:
     for m in 1..NP:
       r1, r2, r3 = 互不相同且 ≠ m 的随机索引
       v = x_r1 + λ (x_r2 − x_r3)                         # 变异 (DE/rand/1)
       j_rand = randint(D)
       u = [v_j if (rand() ≤ CR or j == j_rand) else x_m_j  for j in 1..D]    # 二项交叉
       u = clip(u, B)                                     # 越界处理 (原文未提, 实现必需)
       f_u = ½ Σ_i (g_ref^i − H_i(u))²                    # 每次评估需 I 次射线追踪
       if f_u ≤ f(x_m): x_m ← u                           # 贪婪选择
3. 输出 (N*, S*) = argmin f
```
- 规模：PE 圆环 D=10 → NP=100，每代 100 次评估 × 152 次射线追踪；THZ 模型 D=60 → NP=600，每代 600 次评估。K_max 未给。
- 搜索域收缩（THZ 实验）：每个顶点坐标限制在真值 ±δ（δ=5 mm）的窗口内，把 60 维搜索限制在很小的超立方体中；估计误差在 0.5 mm 内。这是一个强先验（需要知道各顶点的大致位置），作者称之为“弱先验”是相对于 M-ART 需要精确界面而言。
- 病态性来源：不同 (N, S) 组合可能产生几乎相同的正弦图（例如折射率升高与环变厚在时延上部分等价），DE 的全局搜索只能在有界域内缓解。

### 5.5 算法 5.4：校正系统矩阵 L 的构建（式 (18)(19)）
```
输入: (N*, S*), 像素网格 (J 个方格), I 条射线
for i in 1..I:
    polyline_i = [p_0, p_1, ..., p_{V+1}]  ← 算法 5.1 用 (N*, S*) 追踪
    for 每条直线段 (p_v, p_{v+1}):
        for 每个被穿过的方格 j (Siddon/DDA 光线遍历):
            l_ij += 段在方格 j 内的长度
L = sparse(I×J)
```
- 与 X-ray CT 唯一区别是每条“射线”是折线；对每段单独做 Siddon 遍历再累加即可。
- L 极稀疏（每条射线只穿过 O(√J) 个格）。

### 5.6 算法 5.5：TV 正则化 ADMM（Algorithm 3，式 (22)–(29)）
```
输入: L (I×J), g_abs (I), λ (TV 权重), ρ (罚参数), 迭代数 K
初始化: α^0 = 0, γ^0 = 0, u^0 = 0        # γ, u 与 ∇α 同维 (2J: 水平/垂直差分)
for k in 0..K−1:
    # α 更新 (式 25): 二次问题 min ||Lα − g||² + (ρ/2)||γ^k − ∇α + u^k||²
    #   正规方程: (2 LᵀL + ρ ∇ᵀ∇) α = 2 Lᵀ g + ρ ∇ᵀ (γ^k + u^k)
    #   原文"迭代加权策略近似求解" → 实现可用 CG 若干步, 或梯度下降
    α^{k+1} = solve_approx(...)
    # γ 更新 (式 26–28): 软阈值
    γ^{k+1} = soft(∇α^{k+1} + u^k, λ/ρ),  soft(a,τ) = sign(a)·max(|a| − τ, 0)
    # 对偶更新 (式 29)
    u^{k+1} = u^k + ∇α^{k+1} − γ^{k+1}
输出: α* = α^K
```
- 符号说明：按式 (24) 的 scaled form，γ 子问题的近端点应为 ∇α^{k+1} + u^k；原文式 (27) 印作 ∇α^{k+1} − u^k，与式 (26)(29) 不自洽，此处按标准 scaled-form ADMM 取 +u^k。若采用原文的 −u^k，则对偶更新符号也需相应改变，否则不收敛。
- TV 采用各向异性形式（‖∇α‖₁ 对水平、垂直差分分别取绝对值），因此软阈值逐元素。
- λ、ρ 数值原文未给；常规做法 ρ 取 1–10 量级并随迭代调整，λ 用 L 曲线或目视选取。
- 收敛：对凸问题（22），ADMM 保证收敛；线性 ART 与 ADMM 的差异主要来自 TV 项（Table 2：ART 非线性 23.38/0.9176 → ADMM 非线性 23.47/0.9254）。

### 5.7 算法 5.6：完整两阶段重建
```
1. 从每个 (θ, s) 的脉冲提取 ΔT 与 τ; g_ref = c0·ΔT (再减参考), g_abs = ln(1/τ)
2. 选定界面参数化 (圆环: (r, d, x̃, ỹ); 多边形: 顶点坐标) 与折射率个数
3. (N*, S*) ← DE (算法 5.3), 内部调用 算法 5.1/5.2
4. L ← 算法 5.4
5. α* ← ADMM (算法 5.5)
6. 可选: 用 FBP(g_abs) 作为可视化基线 / 初值
```

### 6.1 可以互相借用的算法组件
- 论文二的 CBAM 与论文四的双注意力是同一个模块，可直接互换。
- 论文三的 R2R 自监督损失可用于论文四（无配对 THz 真值），把仿真退化训练换成真实 THz 图像自监督训练。
- 论文三的谱维 PCA 可用于论文二，把 13 幅频点图像先降维到 3–5 个主成分再做超分与融合，减少 GA 的基因长度。
- 论文一的 DGI 作为可微初始重建，可替换任何“测量→图像”的线性反演层。
- 论文五的射线追踪正算子可作为论文二/三中 PSF 的物理来源（折射导致的空间变 PSF），替代各向异性高斯近似。
